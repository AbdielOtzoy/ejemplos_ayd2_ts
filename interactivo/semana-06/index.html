03 / UX Y UI

UX decide si la experiencia tiene sentido; UI hace visible esa decisión.

UX investiga necesidades, estructura recorridos y valida la experiencia. UI define composición, componentes, estados y lenguaje visual.

PREGUNTA GUÍA

PRUEBA 04 / ACCESIBILIDAD

¿Se puede leer y operar?

Texto gris clarito que casi no se ve

Foco invisible. Si usas teclado, buena suerte.

Ver qué falla y cómo corregirlo

Falla: contraste bajo, controles sin significado visible y foco imperceptible.

Corrección: contraste suficiente, etiquetas claras, foco visible y acciones que no dependan solo de un icono.

PRUEBA 05 / ESTADOS

¿La interfaz responde?

...

La pantalla no cambia. El usuario vuelve a hacer clic 17 veces.

Ver qué falla y cómo corregirlo

Falla: no hay estado de carga, confirmación ni error. La persona no sabe si debe esperar o repetir.

Corrección: mostrar reposo, foco, carga, éxito y error con mensajes específicos.

04 / PATRONES DE INTERACCIÓN

El síntoma del problema puede sugerir el patrón.

No se trata de memorizar nombres: se trata de reconocer qué responsabilidad conviene separar y justificar el costo de hacerlo.

DECISIÓN SUGERIDA

Observer

Suscribir componentes a un flujo de eventos.

Úsalo cuando un cambio, como activar un aviso o cambiar el tema, debe notificar a varios elementos sin que el emisor conozca cada receptor.

Evento→Suscriptores→Respuesta
